# PDF24 Creator - PDFs You Can Already Open

PDF24 Creator merges, splits, or prints to PDF from documents you already have and can open. The result is a new file. It does not remove a password, a signature lock, or any other restriction. If a PDF will not open, you need the password from the person who protected it. Keep the original and write the new PDF under another name.

---

## Why It Stands Out

![PDF24 Creator with a document the user can open, ready to save a new PDF](https://help.pdf24.org/en/wp-content/uploads/sites/3/2018/09/merge-pdfs-with-the-pdf24-creator.png)

People hand you a scan, a letter, and a one-page form that need to be one PDF. PDF24 is a Windows toolbox for that job: print to a PDF, join files, or pull pages out, as long as you can already open each file. The toolbox is not a lockpick. A document that asks for a password stays closed until someone who may share that password gives it to you. Stripping a restriction so you can edit a contract you were not supposed to change is outside this use.

Save a new filename. Replacing the only scan with an experiment is how the page disappears. Open the new PDF in a normal viewer and check the page count and the first and last page. A merge that looks right in a thumbnail can still be in the wrong order. If you only needed a copy to send, keep the editable original as well when you still expect to change the wording.

## Core Capabilities

- **Files You Can Open:** Documents and PDFs that already open on this PC.
- **A New PDF:** Merge, split, or print to a file with a different name.
- **Page Order You Check:** Thumbnails are a hint. The opened file is the proof.
- **No Password Removal:** A locked file stays locked without the password you were given.
- **The Original Remains:** The source is not the output unless you chose the same name on purpose.

## Performance Tips

- Work on copies if the scan is the only one.
- Count pages after a merge, including the last page.
- Do not drop in a PDF you cannot open and then look for a bypass.
- Send the new PDF, and keep the original if you may need to redo it.

## Troubleshooting

- A file will not open? You do not have the password. PDF24 will not remove it.
- The merge is in the wrong order? Do not send it. Rebuild from the originals.
- The original scan is gone? You saved over it. Restore from backup before you try again.
- The PDF looks different from the document? Open it outside PDF24 and compare the last page, not only the first.
